## 🏥 Hospital Management System

A professional Hospital Management System developed using Python Flask and SQLite.

## 🚀 Features

- 🔐 Admin Login
- 👨‍⚕️ Doctor Management (Add, Edit, Delete)
- 🧑‍🤝‍🧑 Patient Management (Add, Edit, Delete)
- 📅 Appointment Booking
- 📊 Dashboard with Live Statistics
- 📈 Hospital Analytics Chart
- 📄 PDF Report Generation
- 📊 Excel Report Export
- 🖼️ Doctor & Patient Photo Upload
- ⚙️ Settings Page
- 🔔 Notification Panel
- ⏰ Live Date & Time

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Chart.js
- Bootstrap
- Font Awesome

## ▶️ Installation

```bash
git clone https://github.com/sufiyanmomin01/Hospital-Management-System.git
cd Hospital-Management-System
pip install flask
python app.py
```

Open:

```
http://127.0.0.1:5000
```
